➕ 분모가 다른 분수의 덧셈과 뺄셈, 대분수와 받아내림까지 (5학년 수학)

4학년에서는 분모가 같은 분수끼리 더하고 뺐어요. 5학년에서는 분모가 다른 분수를 계산해요. 핵심은 하나, 먼저 통분해서 분모를 같게 만든다예요. 진분수부터 받아내림이 있는 대분수 뺄셈까지 차근차근 살펴봐요.

1. 왜 통분해야 할까?

12 + 13을 생각해 봐요. 반 조각과 3분의 1 조각은 크기가 달라서 그대로 "2조각"이라고 셀 수 없어요. 둘 다 16 크기의 작은 조각으로 바꾸면 36 + 26 = 56으로 셀 수 있어요.

⚠️ 가장 흔한 실수12 + 13 = 25처럼 분자끼리, 분모끼리 더하는 실수예요. 25는 12보다도 작아서 말이 안 돼요. 답이 처음 수보다 작아졌다면 계산이 틀린 거예요.

2. 진분수의 덧셈과 뺄셈

예제 ①. 34 + 56 = 912 + 1012 = 1912 = 1712

계산 결과가 가분수이면 대분수로 바꾸어 나타내요.

예제 ②. 56 − 14 = 1012 − 312 = 712

💡 끝까지 약분하기답을 쓰기 전에 약분할 수 있는지 꼭 확인해요. 16 + 13 = 16 + 26 = 36 = 12처럼 기약분수로 쓰는 게 깔끔해요.

3. 대분수의 덧셈

대분수의 덧셈은 두 가지 방법이 있어요.

방법 ① 자연수끼리, 분수끼리

213 + 134 = (2 + 1) + (412 + 912) = 3 + 1312 = 3 + 1112 = 4112

방법 ② 가분수로 바꾸어 계산

213 + 134 = 73 + 74 = 2812 + 2112 = 4912 = 4112

자연수가 큰 대분수는 방법 ①이 편하고, 수가 작을 때는 방법 ②도 좋아요. 두 방법의 답이 같은지 비교하면 검산이 돼요.

4. 받아내림이 있는 대분수의 뺄셈

예제. 314 − 123

  1. 통분: 3312 − 1812
  2. 분수 부분 312에서 812를 뺄 수 없어요. 자연수 3에서 1을 받아내려 1212로 바꿔요: 3312 = 21512
  3. 21512 − 1812 = 1712

가분수로 바꾸어 134 − 53 = 3912 − 2012 = 1912 = 1712로 계산해도 같아요.

⚠️ 받아내림 실수자연수 1을 받아내리면서 분자에 10을 더하는 실수가 있어요. 소수나 자연수 뺄셈과 달리, 분수에서 1은 분모와 같은 수의 분자(1212)로 바뀌어요.
